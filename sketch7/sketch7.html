Reflection

I bit off more than I could chew on this one, but it improved my understanding of p5.js. I started with the idea from the warm up of a carnival game where each player wins coins each round of the game. I kept the priveleged advantage, but with three players I had to adjust and down the rabbit hole I went. I had to look up a lot in the p5 reference and in javascript documentation to get syntax correct and to get this to work. Because I don't have a consistent max value, I couldn't get the progress bars to fill up 100%. The upside is that I played around with text positioning, learned some visual techniques and included random values which made the game more dynamic.
