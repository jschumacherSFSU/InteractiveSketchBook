DES 327 Progress Catalog - Welcome

Welcome to my DES 327 Progress Catalog. This is my online journey to learning interactive design. There are four sections highlighting my learning experience. I hope you enjoy looking around.

  1. p5.js Sketches - the first part of the course was spent learning about the p5.js javascript library. We were able to make some cool stuff.
  2. MicroProject - this second leg of the journey was spent focusing on building a specific p5.js project. I decided to build an online test of sorts for color blindness.
  3. Reflections - as we began our final project, we read some really interesting information on the psychology of user design, design heuristics, and some really wise “golden rules” of design. These are my thoughts on the readings.
  4. Interface Dev - this section represents the final stretch as we ended the semester working in Figma to build out prototypes for a full system with both desktop and mobile views. Big learning curve with big rewards.
