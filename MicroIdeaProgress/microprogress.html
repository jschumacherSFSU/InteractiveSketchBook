Week Work Status Thoughts
1
(2/24, 2/26)		 Concept Summary: This interaction will change the color profile of the sketch. The user will answer a question, and based on the answer, the profile will change to a color profile that is accessible to the user.

Primary Variable: let colorProfile = 0; This is the baseline standard color profile of the page. The input value from the user will change this value. The value change will point to an alternate profile based on the input.

Base Build: State 1: colorProfile = 0; user_input = "red deficiency" State 2: colorProfile = 1; screen color display turns to gray.

New Iteration in Wk2 I got some good feedback from classmates in breakout room. Dylan gave me the idea of doing a quiz to make the page more interactive. This adds into the idea today of containment and offset. I forsee asking questions about a box on the screen to test the user's color vision. As the user answers questions, the box will advance to a new position and change color to test the next type of color deficiency. If the user answers a question in the "affirmative", then the box will move along the x axis, otherwise it will move down the y axis of the screen and move along x path. I think I will chart this out on the project chart page to get a better visual concept of what kinds of questions to ask, and how to respond to the user input.
2
(3/3, 3/5)		 Concept Summary v2: This interaction will have a baseline image and the user will open a color image on the sketch. The user will compare the 2 images. If the user looks at the baseline image and the color deficiency (CD) image and it matches for them, they have that color deficiency. If not, then they will go to the next image and do that check and so on until they get to the last image which will be a match with the baseline and verify they have no deficiency in their color perception.

Primary Variable: I have to reconsider this. Depending on the answer the user gives, I may also change the background color for each color test (red, green, blue, yellow)

Base Build: State 1: user will click a button to begin the test. The baseline image will appear. There will need to be a neutral color for the comparison box. The user will click that box to trigger the comparison image for the specific test to appear. There will be 2 buttons > "MATCH" or "NO MATCH". If "MATCH", then message will alert them of the type of deficiency they seem to have and perhaps give a little information like the name of the deficiency and advise them to see their eye doctor. If "NO MATCH", then the background color would change and maybe the box could flash to alert the user to go to the next box. From here it is rinse/repeat until all the CDs are completed.

Pressure: The pressure is based on restrictive access. The user must go through a sequence in order to gain further access. Structural Addition: I will add a reset condition, so when a user selects "MATCH", there will be a message and the "game" will reset.
