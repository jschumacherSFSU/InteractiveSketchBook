Chosen MicroIdea: Idea 3: Improve vision options for screen users

Week Work Status Thoughts
1 Concept Summary: This interaction will change the color profile of the sketch. The user will answer a question, and based on the answer, the profile will change to a color profile that is accessible to the user.

Primary Variable: let colorProfile = 0; This is the baseline standard color profile of the page. The input value from the user will change this value. The value change will point to an alternate profile based on the input.

Base Build: State 1: colorProfile = 0; user_input = "red deficiency" State 2: colorProfile = 1; screen color display turns to gray.

Build Link: Micro Idea 3 Sketch 		Pending I got some good feedback from classmates in breakout room. Dylan gave me the idea of doing a quiz to make the page more interactive. This adds into the idea today of containment and offset. I forsee asking questions about a box on the screen to test the user's color vision. As the user answers questions, the box will advance to a new position and change color to test the next type of color deficiency. If the user answers a question in the "affirmative", then the box will move along the x axis, otherwise it will move down the y axis of the screen and move along x path. I think I will chart this out on the project chart page to get a better visual concept of what kinds of questions to ask, and how to respond to the user input.
