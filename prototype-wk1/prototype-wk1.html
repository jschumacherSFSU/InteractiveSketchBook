Interface Prototype Reflection - Week 1

This week I was able to build out the preliminary layout for my desktop and mobile views and determine the start of the navigation for each.

For the desktop view, I decided to use a standard horizontal navigation bar at the top of the page. This allows for easy access to the different sections of the site and is a familiar layout for users.

For the mobile view, I went for a hamburger menu. This approach is known to most users and is straightforward to implement as it is a series of buttons on a menu page linking to individual pages.

My current navigation is a set of buttons on the homepage which worked for the Sketchbook so far. Now that we're moving into the Interface design, it requires something more sophisticated that can translate from mobile to desktop.

While I usually choose to try to go beyond the scope of the task , I decided to keep things simple since I'm in unchartered territory with the interface design. I think this will allow me to clearly present the pages and allow the broadest set of users to engage with the system. I still need to pay attention to the consistency of the pages. I've tried so far to establish my typographical hierarchy and apply it, but I need to make sure what I built for the desktop last week, will apply to mobile. This will be something I attend to over the next week.
