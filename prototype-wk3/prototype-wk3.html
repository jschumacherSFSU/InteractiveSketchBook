DES 327 Progress Catalog - Prototype Week 3

Interface Prototype Reflection - Week 3

Navigation model: My navigation started in my desktop version as a horizontal nav bar. I realized that I couldn't translate that exactly so I created a vertical segemented drop down nav bar for mobile. I use a hamburger menu to access the menu, then show a section menu that allows the user to access the individual pages. This seems very straightforward and should be familiar to most users. I think it will be easy to navigate on both desktop and mobile.


Hierarchy logic: I relied on my typographical hierarchy to dictate the layout and organization of content across different screen sizes. I created a hierarchy for the desktop version that ended up being too large for the mobile version, so I created an alternate hierarchy for mobile that maintains the same structure but uses smaller text and more compact spacing.


Mobile-first reasoning: I did things in reverse and created a desktop version first, then went back to develop the mobile version. The mobile version made me realize the value of designing for smaller screens first and then adapting to larger screens. Given the need to prioritize access to the content in a manageable way in the mobile version, working small to large is really essential. Keeping things simple first allows the designer to push the limits further on the desktop version.
