UI/UX Reflection - Neilsen Heuristics

Norman and Neilsen

I think the most aligned concern from Norman's work is the signifier. Nielsen's focus is on making sure the user understands how to use the interface with clear signals and communication from the design.

Challenge

The first heuristic that my microproject violates is #3: User Control and Freedom. I don't have alternate paths built into the design to allow a user to change their mind by going back and making an alternate selection. If a user clicks match by accident, they have no way to correct that user error. By adding a confirmation step before committing to their choice it would allow them to change their mind. This would be especially helpful, if they're not clear or confident in their choice.

The second heuristic that my microproject violates is #7: Flexibility and Efficiency of Use. I don't provide shortcuts or accelerators for expert users, which could help them navigate the interface more efficiently. Although the project is simple and has limited options, giving users the option to customize their experience could enhance usability.

Sketchbook Interface Audit

My sketchbook violates #5: Error Prevention. Given the straightforward nature of the interface navigation, I didn't put any safeguards in place to prevent user errors. Adding back/next options, and undo/redo options in each page would greatly reduce the potential for user errors from occurring in the first place.

Hardest Heuristic

The hardest heuristic in my opinion is #9: Help Users Recognize, Diagnose, and Recover from Errors. This heuristic is challenging because it requires anticipating potential user errors and providing clear, actionable feedback to help users recover from those errors. In my microproject, I need to implement better error messaging and recovery options to support users when they encounter issues.
