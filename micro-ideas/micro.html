DES 327 Progress Catalog - Micro Ideas Project

Micro Ideas

  • Idea 1:
    • Title: Call Center or Interactive Menus
    • Issue/Behavior/system: Users often struggle to navigate complex phone menus because the options don't make sense.
    • Interaction rule:
      • input: user calls company
      • changes over time: descriptions of options
      • Friction/delay/limit/uneveness: system doesn't understand input
    • Intended feeling: The user should feel reduced stress.
  • Idea 2:
    • Title: Food Delivery order tracking
    • Issue/Behavior/system: Users want to know that their orders are fulfilled and not missing items.
    • Interaction rule:
      • input: order is placed
      • changes over time: driver is tracked, but not items
      • Friction/delay/limit/uneveness: orders are missing items
    • Intended feeling: The user should feel informed and reassured about their delivery status.
  • Idea 3:
    • Title: Improve vision options for screen users
    • Issue/Behavior/system: not always easily accessible controls to turn on vision accessibility
    • Interaction rule:
      • input: screen is opened
      • changes over time: user can't read the screen
      • Friction/delay/limit/uneveness: colors reduce readability
    • Intended feeling: the user is frustrated and can't access the data fully.
