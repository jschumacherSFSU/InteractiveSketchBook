Interface Prototype Reflection - Week 2

This week I realized that what I had done initiatlly was not the correct way to build in Figma, so I watched videos trying to understand how to build different parts, but that still didn't help. What I needed was some basic instruction in the bones of Figma. I found the Figma for Beginners llink in Canvas and started working through the tutorials. That gave me a better understanding of the basics. I still have more to learn, but it gave me enough to build out my templates to start generating additional pages.

For the desktop view, I pulled all the preliminary pages and hid them. Basically I wanted to start from scratch. I built a generic set of nav bar, header and home page components. This gave me the templates to build the rest of my pages more easily. Now I just need to duplicate them and can start dropping in content information.

For the mobile side, I was able to map out all the pages and connect the menus to the pages. I'm not sure what theses will look like with content. Yikes!
